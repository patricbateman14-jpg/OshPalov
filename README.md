# OSHPALOV — frontend o‘quv loyihasi

Loyiha HTML, CSS, JavaScript va React asosida ishlaydi. Ma’lumotlar `db.json` faylida saqlanadi. JSON Server faqat lokal demo REST API vazifasini bajaradi; bu production backend emas.

## Ishga tushirish

1. Node.js o‘rnating.
2. Repository papkasida terminal oching.
3. Kutubxonalarni o‘rnating:

```bash
npm install
```

4. JSON Serverni ishga tushiring:

```bash
npm run data
```

5. `dashboard.html` faylini Live Server orqali oching. Dashboard ma’lumotlarni `http://localhost:3001` manzilidan oladi.

## Demo imkoniyatlari

- Admin ko‘rinishi: buyurtmalar, bronlar, menyu, xodimlar, mijoz izohlari, promo-kodlar, sotuvlar va kassir smenalari.
- Kassir ko‘rinishi: buyurtmalar, bronlar, sotuvlar va smenalar.
- Menyu, xodim, buyurtma, bron va promo-kod yozuvlarini JSON Server orqali boshqarish.

## Muhim

Bu o‘quv loyihasi. Login/role tanlash demo ko‘rinishida; haqiqiy autentifikatsiya va ruxsatlarni himoyalash yo‘q. JSON Serverni faqat lokal mashinada ishlating.
